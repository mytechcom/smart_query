# 部署手册（MySQL 版）

## 方式一：Docker Compose（推荐，内置 MySQL 8）
一键拉起 MySQL + 后端 + 前端：
```bash
cp .env.example .env      # 填入 DEEPSEEK_API_KEY
docker-compose up -d
```
- 会自动创建 MySQL 8 容器（utf8mb4），并完成建表与 Mock 数据
- API 容器通过 `depends_on: service_healthy` 等待 MySQL 就绪后再初始化
- 容器内 `DB_HOST` 自动指向服务名 `mysql`
- 访问：前端 http://localhost:8501 ，API 文档 http://localhost:8000/docs

停止 / 清理：
```bash
docker-compose down          # 停止（保留数据卷）
docker-compose down -v       # 停止并删除数据（谨慎）
```

## 方式二：本机 MySQL 手动部署

### 1. 准备 MySQL
确保已安装并启动 MySQL（5.7 或 8.0）。数据库 `ecommerce` 无需手动创建，
`init_db.py` 会自动执行 `CREATE DATABASE IF NOT EXISTS`（需账号有建库权限）；
若无建库权限，请手动创建：
```sql
CREATE DATABASE ecommerce DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 2. 配置 .env
```env
DB_TYPE=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your-password
DB_NAME=ecommerce
DEEPSEEK_API_KEY=sk-xxx
```

### 3. 初始化与启动
```bash
pip install -r requirements.txt
python database/init_db.py          # 建库 → 建表 → Mock 数据

uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload   # 终端1
streamlit run web/app.py --server.port 8501                 # 终端2
```

### 4. 验证 MySQL 连接
```bash
python scripts/verify.py --mysql
```
输出 `✅ 数据库连接成功（mysql://...）` 即表示配置正确。

## 方式三：SQLite 本地模式（无 MySQL 服务时）
```env
DB_TYPE=sqlite
DB_PATH=database/ecommerce.db
```
```bash
python scripts/verify.py    # 离线跑通全链路（仍会校验 MySQL DDL 语法）
```
适合无数据库环境下快速体验与教学演示。

## 环境变量
| 变量 | 说明 | 默认值 |
|------|------|--------|
| `DB_TYPE` | 数据库类型：`mysql` / `sqlite` | mysql |
| `DB_HOST` | MySQL 主机（compose 内为 `mysql`） | localhost |
| `DB_PORT` | MySQL 端口 | 3306 |
| `DB_USER` | MySQL 用户 | root |
| `DB_PASSWORD` | MySQL 密码 | 空 |
| `DB_NAME` | 数据库名 | ecommerce |
| `DB_PATH` | SQLite 文件路径（仅 sqlite 模式） | database/ecommerce.db |
| `DEEPSEEK_API_KEY` | LLM API Key | 空 |

## 数据表（7 张，均含中文 COMMENT）
categories / users / products / addresses / orders / order_items / reviews

外键关系：
- products.category_id → categories.id
- order_items.order_id → orders.id
- order_items.product_id → products.id
- orders.user_id → users.id，orders.address_id → addresses.id
- reviews.user_id → users.id，reviews.product_id → products.id

## 常见问题
| 问题 | 排查 |
|------|------|
| 连接被拒绝 | 确认 MySQL 已启动、端口/账号密码正确、防火墙放行 |
| Access denied | 检查 `DB_USER/DB_PASSWORD`；MySQL 8 建议用 `mysql_native_password` 或安装 cryptography |
| 中文乱码 | 已统一 utf8mb4；确认建库语句为 `utf8mb4_general_ci` |
| 外键报错 | 按依赖顺序建表（脚本已保证：categories → users → products → addresses → orders → order_items → reviews） |
| 只想离线体验 | 设 `DB_TYPE=sqlite`，跑 `python scripts/verify.py` |
