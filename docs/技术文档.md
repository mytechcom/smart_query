# 技术文档

## 架构设计

```
用户输入（自然语言）
   ↓
Streamlit 前端 (web/app.py)
   ↓ HTTP POST /api/query
FastAPI 后端 (api/main.py)
   ├─ ① 意图识别 (intent/) → bar / line / pie / table
   ├─ ② NL2SQL (nl2sql/generator.py)
   │     └─ 注入数据库表结构 → LLM 生成 MySQL SQL
   ├─ ③ SQL 安全校验 (nl2sql/validator.py) → 仅允许只读 SELECT
   ├─ ④ 执行查询 (nl2sql/executor.py) → MySQL / SQLite
   ↓
返回 { intent, sql, columns, data }
   ↓
可视化渲染 (visualization/) → PyECharts 图表 / DataFrame 表格
```

## 数据库层设计

连接层 `database/connection.py` 屏蔽两种数据库差异，由 `.env` 的 `DB_TYPE` 决定：

| 能力 | MySQL（默认） | SQLite（本地模式） |
|------|--------------|-------------------|
| 驱动 | PyMySQL | sqlite3（标准库） |
| 参数占位符 | `%s` | `?`（由 `adapt_sql` 自动转换） |
| 忽略重复插入 | `INSERT IGNORE INTO` | `INSERT OR IGNORE INTO`（`insert_ignore()`） |
| 建表语句 | `MYSQL_SCHEMA`（AUTO_INCREMENT + COMMENT + InnoDB + utf8mb4） | `SQLITE_SCHEMA` |
| 自动建库 | 支持（`CREATE DATABASE IF NOT EXISTS`） | 不需要 |

这样既满足生产用 MySQL，又能在无数据库服务的环境下离线跑通与教学演示。

## 核心模块

| 模块 | 职责 |
|------|------|
| `config/` | 配置管理（DB 连接、API Key、常量），提供 `placeholder()` / `insert_ignore()` / `db_label()` |
| `llm/` | LLM 客户端（DeepSeek / OpenAI 兼容），延迟导入 openai，JSON 结构化输出 |
| `intent/` | 意图识别：LLM + 关键词规则兜底（离线可用） |
| `database/` | `connection.py` 连接层 + `init_db.py` 建表 + `mock_data.py` Mock 数据 |
| `nl2sql/` | 表结构注入 → SQL 生成 → 安全校验 → 执行 |
| `visualization/` | PyECharts 柱状/折线/饼 + 表格 |
| `api/` | FastAPI 后端服务 |
| `web/` | Streamlit 前端 |

## 数据流

1. 前端收集用户问句 → 调用后端 `/api/query`
2. 后端先做**意图识别**（决定图表类型）
3. 再把**表结构（DDL + 数据字典）注入 Prompt**，让 LLM 生成 MySQL SQL
4. SQL 经**白名单校验**（仅 SELECT、拦截多语句与写操作）后执行
5. 结果按意图渲染对应图表返回前端

## 安全设计

- SQL 校验：仅允许以 `SELECT` 开头，命中 `drop/delete/update/insert/alter/...` 关键词即拦截，并禁止分号拼接多语句
- NL2SQL Prompt 明确约束只生成只读查询
- `.env` 中的数据库密码与 API Key 不入库（已被 `.gitignore` 忽略）

## 数据模型（7 张表）

```
categories ──< products ──< order_items >── orders >── users
                                  │           │
                                  └── reviews ─┘      addresses
```

- 销售额计算：`SUM(order_items.quantity * order_items.price)`
- 今天：`DATE(orders.created_at) = CURDATE()`
- 近 N 天：`orders.created_at >= DATE_SUB(CURDATE(), INTERVAL N DAY)`
